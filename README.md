# robotics-study-plan

A 10-week robotics study timetable laid out like a school day: five parallel periods
(Electronics, Maths, Mechanical/CAD, Software/ROS 2, Lab) plus a Saturday workshop build.

Live site: https://ashrafsharf.github.io/robotics-study-plan/

Source of truth is `roadmap/` in the local study workspace; `publish-roadmap.sh` copies it here and pushes.
GitHub Actions (`.github/workflows/pages.yml`) deploys every push to `main`.
